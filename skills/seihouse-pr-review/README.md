# Usage

Invoke `seihouse-pr-review` as the mandatory final step before an implementation agent creates or updates a pull request.

Recommended instruction:

> Before creating or updating the PR, invoke the `seihouse-pr-review` skill, fix all material findings, and include the required Self-Review section in the PR description.

This skill is intentionally general and can be used by Codex, Claude, Kimi/Cami, and other coding agents.
