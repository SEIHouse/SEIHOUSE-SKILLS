# SEIHouse Verification

Use `seihouse-verification` for implementation validation and focused pre-PR
self-review. It also supports review-only requests without authorizing edits.

Review the actual changes, run checks suited to the project, fix authorized in-scope
defects, and report evidence and limitations. Reuse recent passing validation when
the relevant code has not changed.

The PR workflow uses this verification before publishing; it does not require a
second identical review or a fixed description template.
