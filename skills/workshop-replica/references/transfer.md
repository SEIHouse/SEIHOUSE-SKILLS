# Workshop synchronization and transfer

## Synchronize a source rename or move

Inspect the authoritative source repository at the intended branch/commit and verify
the current path and export. Use that source's current production terminology;
historical repository names or example symbols do not establish current ownership.

In one focused pass:

1. Update matching reference/development filenames, symbols, and imports when they
   represent the same production concept. Keep visuals intact for a rename-only task.
2. Update workspace imports, the current registry, manifest provenance, and feature
   README source/transfer notes.
3. Search affected files and registrations for retired developer-facing names,
   including props and test references.
4. Preserve deliberately retained API routes, serialized values, database fields,
   storage keys, and historical schema identifiers. Report relevant retained strings.
5. Build and open the preview; verify the new source linkage independently.

Update comparison dates only for source comparisons actually performed. Do not
overwrite an intentionally refined development copy with source changes merely
to synchronize a name.

## Prepare for transfer

Extraction and visual refinement do not authorize production integration. For a
preparation-only task, list the exact verified presentation files and dependencies,
known visual deviations, and the production contracts that an integration will need.
Keep Workshop controls, fixtures, mock timers, and simulator behavior out of that set.

When production transfer is explicitly requested, compare against the current source
again. Apply the approved presentation through the existing production owner and
reconnect its real data, event, accessibility, and lifecycle contracts. Preserve
persisted/API identifiers unless a migration is authorized. Validate the affected
production flow as well as the visual result; a mock preview is insufficient.

Record transfer status only after the actual transfer and its validation. Explain
any remaining difference or blocker instead of claiming parity or completion.
